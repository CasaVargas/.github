# Casa Vargas

Independent software by Jonathan Vargas. Native apps, bought once or free, with no subscriptions and no accounts where one isn't needed.

[casavargas.app](https://casavargas.app) · [hello@casavargas.app](mailto:hello@casavargas.app) · [LinkedIn](https://www.linkedin.com/in/jvargas1023/)

## Open source

| | What it is | Runs on |
|---|---|---|
| **[Nimbus](https://github.com/CasaVargas/Nimbus)** | Every cloud you use, in one window and in Finder. S3, Google Drive, OneDrive, SFTP and fifty more, with rclone as the engine. [About](https://casavargas.app/nimbus/) · [Download](https://github.com/CasaVargas/Nimbus/releases/latest) | macOS |
| **[Deckle](https://github.com/CasaVargas/deckle)** | A morning newspaper for your Kindle, Kobo, PocketBook or reMarkable, built on your own computer, and store-quality books from the EPUBs you own. [About](https://casavargas.app/deckle/) | macOS, Windows, Linux |
| **[DebridDownloader](https://github.com/CasaVargas/DebridDownloader)** | A desktop client for Real-Debrid, TorBox and Premiumize, with resumable multi-connection downloads. [Download](https://github.com/CasaVargas/DebridDownloader/releases/latest) | macOS, Windows, Linux |

All three are free and GPL-3.0.
